Scope and limitations

  • No cloud hosting, backend, database service or hosted AI.
  • GitHub inspection requires internet and may be limited by GitHub's unauthenticated API quota.
  • Browser security may block GitHub fetch requests from a file:// page. If so, use ZIP inspection; no proxy is used.
  • ZIP inspection is static analysis only, not a full malware scan, build or runtime test.
  • License detection is indicative. Always inspect the actual license text and applicable obligations.
  • IndexedDB availability from local file URLs varies by browser. Export reports for reliable backups.
